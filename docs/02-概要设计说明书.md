## 1. 技术选型

| 维度 | 选型 | 理由 |
|---|---|---|
| 语言 | Python 3.12（打包时冻结） | 生态成熟、PyInstaller 支持最好 |
| GUI | **tkinter/ttk**（标准库） | 免额外运行时依赖，exe 体积最小；Windows 自带控件 |
| 读 Excel | **openpyxl** | 纯 Python，无 COM/Office 依赖，可直接打包 |
| 写 Word | **python-docx** | 生成标准 .docx，WPS/Word 均可打开 |
| 文本/网页 | 标准库 | 无依赖 |
| 打包 | **PyInstaller --onefile --windowed** | 单文件、免安装、可自由分发 |
| 测试 | **unittest**（标准库）+ 自建题库 | 零额外依赖，可随源码分发 |

> 依赖仅 3 个：`openpyxl`、`python-docx`、`pyinstaller`（仅构建期）。

## 2. 架构

```
                     ┌────────────────────────────┐
   题库文件 ───────► │  bank_io  (解析/校验/写回)  │
 (xlsx/csv/json/txt) └──────────────┬─────────────┘
                                    │ list[Question]
                                    ▼
  ┌──────────┐   蓝图+选项     ┌──────────────────┐   一轮试卷    ┌──────────────┐
  │  gui.py  │ ─────────────►  │  generator.py    │ ───────────► │ exporter.py  │──► .docx/.txt/.html
  │  cli.py  │                 │  抽题引擎(核心)  │              │  渲染导出    │
  └──────────┘ ◄───统计/预览──  └──────────────────┘  ──────────► └──────────────┘
        ▲                              │
        │                              ▼
   config.py                     coverage 自检 / 警告
```

分层：**模型层（models）→ 数据层（bank_io）→ 领域层（generator）→ 表现层（exporter/gui/cli）**。
领域层为纯函数式、无 IO、无 GUI 依赖，可独立单元测试。

## 4. 数据模型

```python
class QType(Enum):
    SINGLE = "单选题"
    MULTIPLE = "多选题"
    JUDGE  = "判断题"

@dataclass
class Question:
    qid: str            # 稳定 ID：类型序号 + 题干哈希（同一题库内唯一）
    qtype: QType
    stem: str
    options: list[str]  # 原始选项文本，索引 0→A, 1→B ...
    answer_letters: list[str]   # 选择题答案（原字母），排序后
    judge_answer: bool | None   # 判断题答案
    fixed_order: bool   # 答案含「定」→ True
    analysis: str
    src_row: int        # 来源行号，便于回溯

    @property
    def answer_display(self) -> str  # "A" / "ABCD" / "正确" / "错误"

@dataclass
class Blueprint:            # 一张试卷的题型配额
    single: int
    multiple: int
    judge: int

@dataclass
class PaperItem:
    question: Question
    labels: list[str]           # 打乱后显示字母 ['A','B',...]
    texts: list[str]            # 打乱后显示文本
    answer_display: str         # 重映射后的答案
    shuffled: bool

@dataclass
class Paper:
    seq: int                # 全局卷第（从 1 开始）
    round_seq: int
    items: dict[QType, list[PaperItem]]
    def all_items(self) -> list[PaperItem]   # 按 单选→多选→判断 顺序
```

## 5. 核心算法：覆盖式抽题（需求 3）

### 5.1 輪长计算

```
N = max over 题型 t (⌈n_t / k_t⌉)      n_t = 题库中该题型题数，k_t = 每卷该题型配额
```

例：题库 单选 101 / 多选 32 / 判断 30，配额 20/10/10 →
⌈101/20⌉=6，⌈32/10⌉=4，⌈30/10⌉=3 → **N = 2 张/轮**。6 张卷子后三种题型全部题目都出现过。

### 5.2 每题型取题（伪代码）

```
for t in [单选, 多选, 判断]:
    deck = shuffle(题库[t])          # 一轮洗牌一次
    used = []
    for i in 0 .. N-1:
        take = deck[i*k : (i+1)*k]   # 顺序切块
        used += take
        if len(take) < k:            # 牌堆取尽 → 补题
            pool = deck[0 : i*k]     # 本轮已出现过的题目
            need = k - len(take)
            take += sample(pool, need)            # 从已出现过题目随机补
            while len(take) < k:                  # 题库总量 < 配额
                take += choice(deck, ...)
        paper[i][t] = take
```

性质：
- **覆盖性**：一轮内 deck 的每一题恰好被"顺序切块"覆盖一次 ⇒ 并集 = 全题库（证明见 5.4）。
- **定量性**：每张卷子每题型题数恒为 k_t（补题保证）。
- **随机性**：deck 洗牌 + 补题随机抽样 ⇒ 每轮卷面不同。
- **幂等复现**：给定 seed 与题库，结果确定。

### 5.3 打乱与答案重映射

```
if 题型 in {单选,多选} and 打乱开关 且 not question.fixed_order:
    perm = shuffle(range(n_options))          # 每张卷子独立
    labels   = [new alphabet]
    texts    = [orig_options[p] for p in perm]
    new_letters[j] = label of the position where original letter i landed
    answer   = "".join(sorted(new_letters))   # 单选即单个字母
```

- **定题**：`fixed_order=True` 直接跳过 ⇒ 选项与答案原样输出（需求 4）。
- **判断题**：不参与打乱，答案输出"正确/错误"。

### 5.4 覆盖性证明（简述）

牌堆 deck 为长度 n 的随机排列；第 i 卷取 `deck[i·k : (i+1)·k]`。这些区间在 `[0,n)` 上除最后一块外互不重叠且不遗漏，最后一块长度 `n mod k`。因此 `⋃ᵢ take_i = deck = 全题库`。补题只在最后一块之后追加**已出现过**的题，不引入新集合，故并集不变。∎

### 5.5 边界处理

| 情况 | 处理 |
|---|---|
| k_t = 0 | 该题型不参与组卷，也不算入 N |
| 题库中该题型为空且 k_t>0 | 生成前报错（`GenerationError`） |
| n_t < k_t | 允许，卷内重复；`GenReport.warnings` 提示 |
| 用户手填 N' < N | 允许但 `coverage_ok=False`，界面显式警告 |
| 题库异常行 | 导入时跳过并计入 `skipped`，不参与组卷 |

## 6. 导出设计

### 6.1 Word 试卷结构

```
标题：XXX 试卷（A 卷）
说明行：本卷共 40 题，单选题 20 题、多选题 10 题、判断题 10 题；满分 100 分
考生信息：姓名 ________  部门 ________  工号 ________  成绩 ________
一、单选题（每题 1 分，共 20 分）
1. 题干 ……
   A. 选项   B. 选项   C. 选项   D. 选项
……
二、多选题（每题 2 分，共 20 分）
……
三、判断题（每题 1 分，共 10 分）
……
（可选）答案与解析
1. A  解析：……
```

- 分数由 `scoring` 配置（可关闭：不显示分值）。
- 判断题在题干后追加 `（　　　）`。
- 答案区可在卷末，也可 `answers_in_separate_file=True` 时输出独立文件。

### 6.2 HTML / TXT
- HTML 自带打印样式（A4、分页 `page-break`），用户可用浏览器"打印 → 另存为 PDF"。
- TXT 为纯文本，便于导入其他系统。

## 8. 打包设计

```
pyinstaller --noconfirm --clean --onefile --windowed ^
  --name PaperForge ^
  --collect-submodules openpyxl ^
  --exclude-module numpy --exclude-module pandas --exclude-module matplotlib ^
  src/paperforge/__main__.py
```

## 附：Word / PDF 解析设计（vv1.1.0）

### 两条解析通道

```
表格型数据源 ──> rows_to_questions(rows)         # Excel/CSV/TXT/JSON/Word表格/PDF表格兜底
段落型数据源 ──> lines_to_questions(lines)       # Word段落 / PDF文本
```

`TextLine(text, is_heading, source)` 是段落通道的输入单元；docx 按段落切分并**按软换行 `\n` 再切**，
PDF 按页 `extract_text()` 分行。

### 段落解析状态机（`lines_to_questions`）

逐行判定，优先级：章节标题 → 答案行 → 解析/来源行 → 新题起始 → 选项行 → 续行。

* **章节标题**：`一、单项选择题` / `第二部分 多项选择题`；含「案例/主观/简答/论述/计算」的章节标记为 `skip`；
* **新题起始**：`^\d{1,3}[、.．)）]`（小数点后不得紧跟数字，避免 `2.9米` 误判）或 `题干：`；
* **选项行**：`_iter_option_marks()` 扫描标记位置，兼容 `A.`、`A．`、`A、`、`A)`、`A明确内容`、`C  2.5m`，
  以及紧贴中文的 `…人员B.…`；同时排除 `ABC` 等拉丁字母串；行尾若粘连下一题题号则切出并回插行流；
* **答案**：优先独立答案行（`答案：`/`正确答案：`/`参考答案：`），否则取题干括号内**形如答案**的 token
  （多字母/单字母/`√×对错正确错误`），并把该括号替换为作答空位 `（　　）`；`（含）`、`（  ）` 等不动；
* **题型**：章节优先，答案形态兜底；单选章节出现多字母答案时容错为多选并记 warning。

### Word / PDF 读取

* `_read_docx()`：读全部表格（去重合并单元格）+ 段落行，**两种通道都跑一遍取题目更多者**；
* `_read_pdf()`：pypdf 逐页取文本；加密、无文本层（扫描件）、损坏文件分别给出可读中文提示；
* `_expand_combined_options()`：把「选项挤在一列」的表格展开为 选项A…选项H；
* 失败降级：docx 两通道都为 0 题、PDF 段落解析为 0 题时抛出可读 `ValueError`，不崩溃。
