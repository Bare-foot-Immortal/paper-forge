## 1. 项目背景与目标

培训、考试、技能比武等场景中，命题人需要从一份题库中反复抽题组成多套试卷，且要求"一批试卷轮完后，题库中的题目必须都被考到过"。人工组卷存在三个痛点：

1. **覆盖不可控**：手工抽题容易出现某些题目长期不被抽中；
2. **格式转换繁琐**：组好的卷子还要手工排版、做答案页；
3. **无法分享**：很多工具依赖特定环境，无法直接发给同事使用。

本软件目标：**导入题库 → 设定各题型数量 → 一键生成一整轮（覆盖全部题目）试卷与答案 → 导出 Word/文本/可打印网页**，并打包为免安装单文件 exe，可自由分享。

## 2. 用户与使用场景

- **主用户**：企业安全培训管理员、考评员、教师、比武出题人（非技术背景）。
- **使用方式**：双击 exe → 图形界面操作，无需命令行、无需安装 Python。
- **典型场景**：
  - 场景 A：题库 52 题，每卷 40 题（单选 20 / 多选 10 / 判断 10），生成 1 轮 N 张卷子，要求 52 题全部出现过。
  - 场景 B：比武用 A/B 卷，选项顺序打乱，防止相邻考生抄袭。
  - 场景 C：把生成的 Word 卷子直接发给同事打印。

## 3. 术语定义

| 术语 | 含义 |
|---|---|
| 题库 | 存放题目的数据源，支持 xlsx/csv/json/txt |
| 试卷蓝图 | 一张试卷的题型配额，如 单选 20 / 多选 10 / 判断 10 |
| 轮（Round） | 一组试卷，其全体题目并集 ⊇ 题库全体题目 |
| 轮长 N | 一轮包含的试卷张数，N = max(⌈该题型题库量 / 该题型每卷配额⌉) |
| 定题 | 答案在题库中标注为"定"的多选题，选项顺序固定，不允许打乱 |
| 补题 | 某题型题库取尽后，从本轮已出现过的题目中随机补足配额 |

## 4. 功能需求

### FR-1 题库导入
- FR-1.1 支持 **.xlsx/.xlsm**（按 `题型 / 题目标题 / 选项A…选项H / 解析 / 答案` 列头识别），兼容仅含中文列头、列顺序可变。
- FR-1.2 支持 **.csv**（UTF-8 / UTF-8-BOM / GBK 自动识别）、**.txt**（制表符或竖线分隔）、**.json**。
- FR-1.3 题型取值兼容：`单选题/单选`、`多选题/多选`、`判断题/判断`。
- FR-1.4 答案兼容：`A`、`ABCD`、`正确/错误`、`对/错`、`√/×`、`T/F`、`是/否`；多选题答案可带 `（定）`/`(定)`/`定` 后缀。
- FR-1.5 导入后展示统计：总题数、各题型题数、含定题数、异常行提示（缺题干、缺答案、选项不足等），异常行不进入题库并被列出。

### FR-2 试卷蓝图配置
- FR-2.1 可自定义每张试卷的**各题型数量**（单选 / 多选 / 判断，可为零）。
- FR-2.2 可自定义一轮的**张数**：默认自动计算覆盖题库所需的最小张数 N，允许手工增大；手工小于 N 时给出"无法覆盖全部题目"的明确提示。
- FR-2.3 可自定义生成的**轮数**（1 轮 = N 张）。
- FR-2.4 实时校验：配额为 0 的题型不参与组卷；某题型题库为空但配额 >0 时报错。

### FR-3 抽题引擎
- FR-3.1 **覆盖性（核心）**：一轮内每种题型的题目按"洗牌后顺序切块"抽取，保证一轮结束时该题型题库全部至少出现一次。
- FR-3.2 **补题**：某题型最后一卷剩余题量不足配额时，先把剩余题目全部放入，差额从**本轮已出现过的该题型题目**中随机补足，使每张卷子题目数量严格等于配额。
- FR-3.3 **题型独立**：各题型分别维护牌堆与轮次，互不挤占。
- FR-3.4 **随机性**：支持固定随机种子复现同一套卷子（可选），默认随机种子来自系统熵。
- FR-3.5 **卷内不重复**：同一张卷子内尽量不重复同一道题；仅当该题型题库总量小于配额时才会重复，并给出警告。
- FR-3.6 **覆盖自检**：生成后自动校验"本轮题库并集 == 全题库"，给出校验结果。

### FR-4 选项打乱（防抄袭）
- FR-4.1 单选、多选**分别**可开关"打乱选项顺序"，判断题不参与打乱。
- FR-4.2 打乱后**答案自动重映射**到新的选项字母。
- FR-4.3 **定题保护**：题库答案标注为"定"的多选题（如 `BC（定）`）**永不打乱**，答案保持原样。
- FR-4.4 打乱对每张卷子独立生效。

### FR-5 输出与导出
- FR-5.1 导出 **Word（.docx）**：含卷头、考生信息栏、题目区、答案区；答案可"附在卷末"或"单独成文件"；解析可选。
- FR-5.2 导出 **可打印 HTML**：浏览器直接打印或"另存为 PDF"。
- FR-5.3 导出 **纯文本（.txt）**：便于二次加工。
- FR-5.4 支持"每张卷子一个文件"与"全部合并为一个文件"两种打包方式。
- FR-5.5 文件名规范：`试卷_A_单选题20-多选题10-判断题10.docx`、`答案_A.docx`。

### FR-6 界面与交付
- FR-6.1 图形界面（免安装），中文。
- FR-6.2 可在界面预览生成的试卷与答案。
- FR-6.3 提供命令行模式（可选，供批量脚本调用）。
- FR-6.4 打包为**单文件 exe**，可复制到任意 Windows 机器直接运行。

## 6. 边界与假设（明确记录）

1. 题库答案列采用"字母/文字"表达答案，不接受图片题、公式图片题（题干为纯文本）。
2. 判断题的标准答案为"正确/错误"，界面与答案页按此输出。
3. 「定」只对多选题生效；若单选题答案被标注"定"，等价于不打乱该题（保守处理）。
4. 每卷配额之和 = 试卷题目总数；若某题型题库量 < 配额，允许卷内重复并显式提示。
5. 一轮的轮长 N 由"覆盖性"决定：N = max(⌈题库量_题型 / 配额_题型⌉)，用户可增大不可实质缩减（缩减即放弃覆盖，需显式确认）。
6. 打乱仅改变选项显示顺序，不改变题目内容与答案正确性。
7. 软件不提供题库在线同步、账号、云存储（本期范围外）。

## 附：题库导入格式（vv1.1.0 新增）

除原有 Excel（`.xlsx/.xlsm`）、文本（`.csv/.txt`）、JSON 外，新增：

| 格式 | 版式 | 要求 |
|---|---|---|
| Word `.docx` `.docm` | 表格型 | 列头同 Excel；选项可合并在一列（`A.甲 B.乙`），自动展开 |
| Word `.docx` `.docm` | 段落文本型 | 章节标题标题型（如「一、单项选择题」）；题干/选项/答案分行或同行；答案可嵌在题干括号内（`（C）`、`（  BCE ）`、`（√）`）或独立成行（`答案：C`） |
| PDF `.pdf` | 文本型 | 读取文本层；先按段落解析，失败再按多空格分列兜底；扫描件不支持 |

约束：

1. 判断题不设选项；三题型以外的主观题/案例题章节自动跳过；
2. 无法解析的行不进入题库，但必须给出「行号 + 原因 + 题干片段」；
3. 新增依赖（python-docx、pypdf）必须可随 PyInstaller 打入单文件 exe；
4. 原有 `.xlsx/.csv/.txt/.json` 行为不得回归。

详细写法与边界见 `docs/04-Word与PDF题库导入说明.md`。
